# 🚀 Project Ideas – Effort vs. Impact Matrix

A consolidated list of project ideas focused on AI-powered education tools and LTI 1.3 integration with Canvas LMS. Each idea includes the expected effort, potential impact, and key notes.

---

## 📊 Effort vs. Impact Matrix

| Project                                | Effort     | Impact    | Notes |
|----------------------------------------|------------|-----------|-------|
| **1. A-Level Physics MCQ App**         | High       | ⭐⭐⭐⭐      | Build a large question bank using OpenAI. Focus on tagging, topic coverage, student tracking, and content ownership. Long-term high value. |
| **2. Canvas Chat Bot (LTI 1.3)**       | High       | ⭐⭐⭐⭐      | Teachers upload documents → generates course-specific chatbot. Complex LTI integration and document processing. High utility for teachers. |
| **3. AI-Powered Kahoot Alternative**   | Medium     | ⭐⭐⭐       | Real-time quiz tool that generates questions from uploaded content. Great for learning Railway deployment, OpenAI usage, and rapid prototyping. |
| **4. Organic Attendance (LTI 1.3)**    | Low        | ⭐⭐        | Lightweight Django app. Student-initiated attendance tracking with audit features. Perfect for learning LTI 1.3 basics. Useful proof-of-concept. |

---

## 📌 Suggested Development Strategy

1. **Start with Organic Attendance** – low effort, ideal for learning and validating LTI 1.3 with Django.
2. **Tackle the Canvas Chat Bot** – leverage LTI knowledge for a more powerful, complex tool.
3. **Explore Kahoot Alternative** – develop in parallel as a learning playground for Django + Railway + OpenAI.
4. **Invest in A-Level MCQ App** – this becomes the flagship offering with long-term value and monetization potential.

---

## 🛠️ Shared Technologies

- **Django** – all projects use Django as core framework.
- **OpenAI API** – used for generating questions and chatbot responses.
- **LTI 1.3** – central to Canvas-integrated tools (#2 and #4).
- **Railway** – targeted deployment platform for experimentation.
